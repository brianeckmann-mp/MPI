Dashboard Update Commands
Pull the source repos and regenerate the design system dashboard data.
Back to dashboard
The update command refuses to pull if either sibling repo has uncommitted changes. Commit, stash, or discard those changes first, then run the update again.
Update Everything
Fetches and fast-forwards the configured branches, then writes the dashboard snapshot.
npm run dashboard:update
Preview Git Commands
Shows the exact git commands without pulling or changing branches.
npm run dashboard:update:dry-run
Refresh Snapshot Only
Rebuilds dashboard data from current local repo state without fetching remote changes.
npm run dashboard:snapshot
Run Dashboard Locally
Starts Vite. The dashboard reads live repo data from the local API while this is running.
npm run dev

Override Example
Use this when a repo lives somewhere else or you need a different branch for a one-off refresh.
MAXPREPS_DESIGN_SYSTEM_BRANCH=main MAXPREPS_REACT_BRANCH=master npm run dashboard:update
Static build fallback data is written to projects/design-system-dashboard/data/live.json. In dev, the dashboard uses /api/design-system-dashboard first and falls back to the snapshot if the API is unavailable.
