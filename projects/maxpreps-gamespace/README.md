# MaxPreps GameSpace

A leadership-facing concept prototype demonstrating the depth of MaxPreps coverage through a layered interactive arena.

## Run

```bash
npm install
npm run dev
```

The featured game and statistics are based on the MaxPreps box score and editorial recap for Mater Dei at Centennial on September 12, 2025. Spatial player positions and animated routes are authored concept visualizations, not tracking data.
